# Audio assets (not in the repo — licence)

The music and SFX used by the template are free Mixkit-licence downloads. That licence lets you use them in videos
but not redistribute the raw files, so add them yourself with exactly these names (or change the names in
`src/timeline.ts` → `SFX` and `src/Main.tsx` → BGM).

- `bgm/tonight-hiphop.mp3` — background track, ~105 BPM (beat grid in `timeline.ts`: `BEAT_SEC`, `BEAT_PHASE`)
- `sfx/pop.mp3` — avatar pop-in
- `sfx/bass-hit-short.mp3` — camera punch
- `sfx/whoosh-fast.mp3` — scene whip-pans
- `sfx/switch-tap.mp3` — CTA cursor click
- `sfx/ui-success-soft.mp3` — CTA confirm, "correct" beats
- `sfx/sparkle-touch.mp3` — small sparkle accents
- `sfx/ui-message-pop.mp3` — card / chip pop
- `sfx/ui-select-click.mp3` — list ticks
- `sfx/hit-weak.mp3` — "wrong" / stamp hits
- `sfx/marker-pen-line.mp3` — strike-through / writing
- `sfx/chime-crystal.mp3` — end-of-teach sting
- `sfx/clock-tick-single.mp3` — timers
- `sfx/swoosh-quick.mp3` — punch-line transitions

Any short UI sound works; keep them under ~1 s and normalised.
